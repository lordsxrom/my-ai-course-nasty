# Учебные приложения

Здесь **нет готового кода** — только указатели. Каждый студент собирает приложения в `projects/` **в своём workbook** (clone из template).

---

## Зачем отдельная папка

Curriculum на GitHub автора = задания.  
Workbook студента = задания + **твои** `projects/`, сдачи, practice.

Так ответы не смешиваются с учебником.

## Как создать приложение

1. Открой урок недели  
2. В Cursor:

```text
Используй skill scaffold-web-tip-calculator.
Фаза: scaffold.
```

3. Прими diff, проверь smoke из урока  
4. `git commit` + `git push`

Каталог всех scaffold skills: [teacher/skills/scaffold-apps/README.md](../teacher/skills/scaffold-apps/README.md)
