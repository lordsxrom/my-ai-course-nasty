# Author harness — maintainer curriculum

Инструменты **автора** курса (`lordsxrom/ai-course`): новые недели, rubrics, push, согласованность docs.

**Не путать с:**

| | Author | Teacher |
|---|--------|---------|
| Кто | Человек, который ведёт репо curriculum | Виртуальный проверщик ДЗ в Cursor |
| Папка | `author/` | `teacher/` |
| Студент | **Не использует** | Использует (`проверь домашку`) |

## Структура (по мере надобности)

```text
author/
  rules/     # стиль уроков, структура module
  skills/    # publish-week, sync-spec-scaffold, …
```

## Студентам

Если эта папка приехала в workbook из template — **игнорируй**. Домашку сюда не клади.
