## Контекст в Cursor

| Ситуация | Действие |
|----------|----------|
| Смена темы / урока | Новый чат |
| Один файл | `@файл` |
| Зона недели | `@папка` |
| Agent пишет не туда | Allowlist + Reject |

## HAND / AI / MIX

- **HAND** — бриф, теория, вердикт, квиз  
- **AI** — тело рабочего артефакта через Agent  
- **MIX** — бриф руками, тело AI, приёмка руками  

К концу курса доля AI на артефактах растёт; твоя ценность — заказ и приёмка.

## Два контура харнеса

- **Student (portable):** `student/` — переносишь в `~/.cursor/` или другие проекты  
- **Teacher:** `teacher/` — только курс  
- **Author:** `author/` — только maintainer  
- **Entrypoint:** `.cursor/` — stub, не копировать
