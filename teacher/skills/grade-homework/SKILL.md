# Grade homework (Teacher)

Часть **Teacher** (`teacher/`). Не копировать в другие проекты как «свой» skill.

Перед проверкой прочитай также `teacher/rules/teacher.mdc`.

## Вход

Определи тип проверки из сообщения:

### A) Урок

- Есть `week` и `lesson` (например: неделя 1, урок 4).
- Рубрика: `weeks/WW/rubrics/lesson-LL.md`
- Сдача: `weeks/WW/submissions/lesson-LL.md`
- Доп. артефакты — из рубрики и текста урока `weeks/WW/lessons/…`

### B) Checkpoint модуля

- Фразы вроде `проверь checkpoint недели 1` / `checkpoint модуля 1`.
- Рубрика: `weeks/WW/rubrics/checkpoint.md`
- Сдача: `weeks/WW/submissions/checkpoint.md`
- Также читай `weeks/WW/CHECKPOINT.md` для списка обязательных путей.
- Проверь **существование** перечисленных артефактов на диске, не только галочки в сдаче.

Если рубрики нет — скажи и остановись.  
Если сдачи нет — `Rework`, укажи путь.

Нули в путях: `01`, `02`, …

## Процедура

1. Пройди **все** Critical пункты. На каждый — Pass/Fail + улика (путь, цитата, «файла нет»).
2. Пройди Minor — ok или note.
3. Вердикт:
   - есть Critical Fail → `Rework`
   - все Critical Pass, есть Minor notes → `Pass with notes`
   - всё чисто → `Pass`
4. При `Rework` — нумерованный список исправлений **без** готовых ответов за студента.

## Запрещено

- Ставить Pass «за старание»
- Дописывать студенту сдачу или шаблоны молча
- Менять rubric под ответ студента
- На checkpoint засчитывать урок, если `lesson-XX.md` — пустая копия template без содержательных ответов
- Засчитывать **AI**-часть, если студент явно сделал артефакт руками вопреки уроку (нет `created_via: agent` / признание «набил сам»)
- На **HAND**-частях: если текст выглядит как «Agent, ответь на вопросы урока» без своей приёмки — Fail или Rework с указанием переписать своими словами

## Метки HAND / AI / MIX

Смотри таблицу в уроке. Critical часто завязан на метку: неверный способ получения артефакта = Fail.
